# 「收益与快照」页 · Figma 图层树

先画这一页，因为它的组件最全（指标卡、卡片、图表、表格、表单、提示条都有）。画完它，其余 14 页基本是替换区块。

数值都来自现有代码（`frontend/src/styles/styles.css` 和各 `.vue` 的 scoped style），可以直接照用。

---

## 一、两个画布

| 画布 | 宽 | 高 | 背景 |
|---|---|---|---|
| 桌面 `page/收益与快照 · Desktop` | 1280（内容 1240 + 左右各 20） | Hug contents | `color/bg1` |
| 手机 `page/收益与快照 · Mobile` | 560（内容 520 + 左右各 20） | Hug contents | `color/bg1` |

两个 Frame 并排放在画布上，间距随意。

**桌面 Frame 的设置**：Auto layout 方向 `↓`、padding `22 / 20 / 40 / 20`、gap `14`。

> gap 14 对应代码里每块底部的 `margin-bottom: 14px`，padding 对应 `.app-container`。

## 三、逐块规格

### 0. 顶栏（组件，所有页面共用）

| 项 | 值 |
|---|---|
| 布局 | →，space-between，padding `12 / 14`，gap 16 |
| 外观 | 圆角 14，边框 1px `color/border`，背景 `color/surface`，阴影 `shadow/sm` |
| 左 | 品牌名「真仓账本」18 / Semi Bold |
| 中 | 4 个分组按钮：padding `7 / 10`，圆角 10，13px；当前分组用 `color/chipActiveBg` + 主色文字 |
| 右 | 4 个图标按钮 32×32，圆角 10，背景 `color/headerBtnBg`，边框 `color/headerBtnBorder` |
| 高 | 约 62（内容撑开） |

### 1. 快照提醒条

→、space-between、gap 12、padding `8 / 14`、圆角 10、背景 `color/chipBg`、边框 1px `color/border`。
左侧一行 13px `color/muted`（如「今天还没有快照 · 16:40 自动记录」），右侧 1 个按钮。

### 2. 提示条 · 未录流水（`el-alert` 警告态）

圆角 8、padding 12、背景 `color/warnSoft`、左边一根 3px `color/warn` 竖条或警告图标。
第一行 13 / Semi Bold `color/warn`（「外部资金流水未录入」），第二行放两个按钮：主按钮（warning）+ 普通按钮。

### 3. 一句话故事卡

| 项 | 值 |
|---|---|
| 卡片 | 圆角 12、边框 1px `color/border`、背景 `color/surface`、阴影 `shadow/sm`、padding `16 / 16 / 14` |
| 布局 | →，space-between，gap 12，顶部对齐 |
| 句子 | 17 / Bold(750) / 行高 1.45；涨用 `color/up`、跌用 `color/down`、中性用 `color/text` |
| 右侧标签 | 圆角 6、padding `2 / 8`、12px `color/muted`、背景 `color/chipBg` |

### 4. 指标卡（组件，两个变体）

| 项 | 普通卡 | 主卡 |
|---|---|---|
| 尺寸 | 宽 Fill container、高 ≥108 | 同 |
| padding | 16 | 16 |
| 圆角 | 12 | 12 |
| 标签 | 12 / Semi Bold `color/muted` | 同 |
| 数值 | 22 / Semi Bold，等宽字体，`color/text` | 30 / Semi Bold，等宽字体，`color/primary` |
| 涨跌 | 数值或百分比用 `color/up`（红）/ `color/down`（绿） | 同 |

数值必须用等宽字体 + 数字用 `tabular-nums` 的思路（Figma 里就是选等宽字族 + Letter spacing -3%）。

### 5. 核心指标行

→、gap 12，放两张卡：`现在总资产`（主卡，Fill）、`累计净投入`（普通卡，Fill）。

### 6. 收益尺（5 张尺度卡）

| 项 | 值 |
|---|---|
| 容器 | →，5 列，gap 10 |
| 卡片 | padding `10 / 12`、圆角 10、边框 1px `color/border`、背景 `color/surface` |
| 标签 | 12 `color/muted`（今天 / 本月 / 今年 / 近一年 / 开仓至今） |
| 数值 | 15 / Bold，涨 `color/up`、跌 `color/down` |
| 百分比 | 12 `color/soft`，同色规则 |
| 选中态 | 边框换成 `color/primary`（可再加 `color/primarySoft` 底） |
| hover 态 | 边框变主色 + 整体上移 1px |

这一行是**时间范围选择器**，点哪张整页口径跟着变，所以选中态要明显。

### 7. 卡 · 最近 7 个交易日

卡片 padding 16。内部：

- 标题行：`最近 7 个交易日` 16 / Bold + 下面一行 13 `color/muted`（「按已有快照的最近 7 个交易日统计（不是自然日）；本月 / 今年看上方收益尺」）
- 指标行：→、4 列、gap 12，用普通指标卡
  - `7 日累计`（涨跌色）
  - `涨 / 跌 天数`（值形如 `4 / 3`）
  - `最好一天`（值形如 `09-18 +¥7,494.00`，长度 ≤20 字符，这是硬约束，超了实现时会被截断）
  - `最差一天`（同上）

### 8. 卡 · 每日收益

- 标题行：`每日收益` 16 / Bold，右侧放单选组（近 7 / 30 / 90 天，`el-radio-button`）
- 指标行：→、4 列、gap 12：`近30天累计`（涨跌色）/ `涨 / 跌 天数` / `最好一天` / `最差一天`
- 图表占位：Fill × 220，圆角 8，背景 `color/bg0`，中间写「柱状图」
- 表格 · 每日收益：6 列 —— 日期 / 当日盈亏 / 当日涨跌 / 期末总资产 / 间隔 / 价格

### 9. 快照明细组

外面前面加一行裸标题 `快照明细`（16 / Bold，不带卡片）。

**工具条**：→、右对齐、gap 8，一个日期范围选择器（宽 240，高 32，圆角 8）+ 三个小按钮。

**表格规格（这一页所有表格都一样）**：

| 项 | 值 |
|---|---|
| 表头 | 高 40、文字 12 / Semi Bold `color/muted`、背景 `color/chipBg` |
| 行 | 高 40、上下 padding 8、左右 12、正文 13 |
| 斑马纹 | 偶数行背景 `color/bg0` |
| 边框 | 行之间 1px `color/border` |
| 首列冻结 | 画法见下 |

**冻结首列的画法**：把表格放进一个宽度固定的 Frame，打开 **Appearance → Clip content**，内容超出右边就被裁掉（表达「横向滚动」）；首列单独一个子 Frame，固定在最左，右下角加 1px 分隔线。

**块内的表格**：

- 快照历史记录：8 列 —— 日期 / 投资市值 / 银行存款 / 证券现金 / 申购在途 / 持仓浮盈 / 全周期盈亏 / 投资占比
- 区间变化明细：5 列 —— 项目 / 期初 / 期末 / 变化额 / 变化率
- 当前资产结构：饼图占位 180×180（`color/primary`、`color/up`、`color/down`、`color/warn` 四段）+ 右侧图例
- 人工对账：三行「实盘总资产 / 当日计算快照 / 误差」用 →、space-between、上下 6 的间距；下面一行三字段表单（日期 / 金额 / 备注）+ 保存按钮

### 10. 辅助指标行

→、2 列、gap 12，两张普通指标卡：`当前仓浮盈+分红`、`距目标收益缺口`。

### 11. 卡 · 组合归因与风险

- 标题行 `组合归因与风险` 16 / Bold
- 指标行 3 列：`最大回撤` / `当前离峰值` / `年化波动`
- 下面加一个小标题 `风险一览` + 两列文字说明

### 12. 卡 · 组合资金流水

- 标题行 `组合资金流水（外部投入/取出）` 16 / Bold + 右侧标签（笔数）
- 表格 · 建议草稿：5 列（日期 / 金额 / 方向 / 来源 / 操作）
- 表单行：→、gap 12，四个字段（日期 / 金额 / 方向 / 备注）+ 保存按钮
- 表格 · 流水：6 列（日期 / 金额 / 方向 / 备注 / 来源 / 操作）

## 四、手机稿（560）怎么改

不用重排，只改三处：

- 所有多列栅格 → 单列（指标卡的宽还是 Fill container，自动就是一列）
- 收益尺 → **2 列**（代码里窄屏是 2 列，5 张卡排 3 行）
- 顶栏 → 两行：第一行品牌 + 右侧按钮，第二行分组导航横滑

表格照画，靠 Clip content 表示横向滚动。
